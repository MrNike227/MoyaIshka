# Версия 4.2.5 — устойчивый локальный самоанализ

## Цель

Устранить общий сбой саморазвития при ответе локальной Ollama:
`HTTP 500: prediction aborted, token repeat limit reached`.

## Исправление

- Самоанализ распознаёт аварийное завершение генерации из-за повторяющихся токенов.
- Выполняется одна повторная попытка с параметрами `repeat_penalty=1.15`, `repeat_last_n=128`, `top_k=40`, ограничением ответа до 768 токенов и уменьшенным batch.
- В повторный запрос добавляется короткое требование сохранить JSON-формат и не повторять фрагменты.
- Если повторная попытка снова приводит к зацикливанию, приложение показывает понятную ошибку вместо сырого HTTP 500.
- Ранее добавленный переход на CPU при аварийном завершении `llama-server` с `0xC0000005` сохраняется.
- Обычный чат не меняет параметры и не использует специальный повтор для самоанализа.

## Повторная генерация diff

- Если модель вернула пояснение или код без заголовка блока `@@`, приложение не останавливается после первой ошибки.
- До трёх попыток выполняется генерация, проверка извлечённого diff и применение к копии исходного текста без записи на диск.
- Для повторов уточняется формат unified diff, а температура генерации постепенно повышается с 0.15 до 0.35.
- Если все попытки неудачны, отображается понятная итоговая причина; исходный файл остаётся нетронутым.

## Проверки

- Повтор запроса с защитными параметрами после `token repeat limit reached`.
- Понятная ошибка при повторном зацикливании.
- Отсутствие повторов в обычном чате.
- Регрессионные проверки CPU fallback и выбора локальной модели без API-ключа.
- Полный набор тестов и проверка автономной Windows-сборки в GitHub Actions.

Повторная попытка снижает вероятность сбоя, но не гарантирует исправление дефекта самой модели или Ollama.
