# Версия 4.2.4 — локальный самоанализ без API-ключа

## Цель

Исправить запуск самоанализа, когда обычный режим чата установлен в «Только онлайн», но API-ключ не настроен, а локальная модель Ollama доступна.

## Поведение выбора модели

- Если выбран режим «Только локально», самоанализ использует Ollama.
- Если API-ключ отсутствует, самоанализ использует настроенную локальную Ollama независимо от режима обычного чата.
- Если API-ключ указан и выбран режим «Только онлайн», самоанализ использует облачную модель.
- Если локальная модель не настроена или недоступна, показывается ошибка подключения к Ollama, а не вводящее в заблуждение требование API-ключа.

## Проверки

- Регрессионный тест: «Только онлайн» + пустой API-ключ + заданная Ollama → используется локальная модель.
- Регрессионный тест: «Только онлайн» + заданный API-ключ → используется облачная модель.
- Полный набор unit-тестов и Windows onedir-сборка запускаются в GitHub Actions.

Самоанализ только предлагает изменения. Автоматическое применение кода не включается.
