ОБНОВЛЕНИЕ «МОЯ ИИШКА» ДО ВЕРСИИ 4.1.2

Что исправлено:
- Интернет-поиск в чате работает без API-ключа.
- Если облачная/локальная языковая модель не подключена, показываются найденные источники, выдержки и URL.
- API-ключ нужен только для генеративных ответов облачной модели.
- Сборщик EXE включает GitHub workflow в исходную папку, чтобы мастерская саморазвития могла видеть его в EXE.
- Номер приложения оставлен 4.1.2.

Как обновить GitHub-репозиторий:
1. Сделайте резервную копию текущего репозитория/папки.
2. Распакуйте этот ZIP во временную папку.
3. Скопируйте ВСЁ содержимое архива в корневую папку локального репозитория, соглашаясь на замену файлов. Не удаляйте папку .git.
4. Проверьте, что main.py содержит APP_VERSION = "4.1.2".
5. Через GitHub Desktop сделайте Commit с сообщением «Fix web search without API key» и нажмите Push origin.
6. На GitHub откройте Releases → Draft a new release.
7. В поле Tag выберите «Create new tag» и введите v4.1.2; Target — main.
8. Опубликуйте релиз. Workflow Build Windows release соберёт MoyaIshka.exe и прикрепит MoyaIshka.exe.sha256.
9. На вкладке Actions проверьте зелёную галочку. В Releases дождитесь появления обоих файлов.

Важно:
- Не создавайте тег v4.1.2 до загрузки изменённых файлов в main.
- Поиск требует подключение к интернету, но не API-ключ.
- Без API и без Ollama приложение не генерирует свободное AI-резюме, а показывает найденные выдержки и ссылки. Для AI-синтеза без облачного API нужна локальная модель Ollama.
- Windows EXE должен быть собран GitHub Actions на Windows; в этом исходном архиве готового EXE нет.
