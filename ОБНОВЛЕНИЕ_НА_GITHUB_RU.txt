ОБНОВЛЕНИЕ «МОЯ ИИШКА» ДО ВЕРСИИ 4.1.5.1

1. Распакуйте GitHub patch 4.1.5.1 в корень локального репозитория с заменой файлов.
2. ОБЯЗАТЕЛЬНО замените .github/workflows/release.yml.
3. Выполните Commit и Push в main.
4. Создайте тег v4.1.5.1 либо запустите обновлённый workflow вручную с release_tag=v4.1.5.1.
5. Убедитесь, что workflow называется Build Windows release — verified 4.1.5.1.
6. Не скачивайте релиз, если EXE smoke-test не прошёл.

В 4.1.5.1 сборка использует активный Python из setup-python, явно включает cryptography и проверяет импорт/шифрование внутри готового Windows EXE.
