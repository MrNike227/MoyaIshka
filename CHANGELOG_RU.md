# История изменений — Моя ИИшка

## 4.1.2 — интерфейс, установка обновлений и исправление веб-поиска

- Исправлено: интернет-поиск в чате больше не требует API-ключа. Если языковая модель не настроена, показываются найденные источники, выдержки и ссылки.
- Разделены требования к веб-поиску и облачной генерации ответов: API-ключ нужен только для облачной модели.

- Добавлена постоянная тёмная верхняя панель приложения с номером версии.
- Обновлены карточки недавних диалогов: увеличены шрифт, отступы, предпросмотр и выделение активного диалога.
- Сделаны более заметные флажки: пустой квадрат означает «нет», заполненный тёмно-фиолетовый квадрат — «да».
- Увеличен базовый размер текста; сохранён шрифт Segoe UI как наиболее совместимый с Windows 10.
- Добавлен выбор постоянной папки установки и кнопка переноса текущей EXE-сборки в выбранную папку.
- Обновления после проверки SHA-256 устанавливаются в сохранённую папку; отдельный помощник дожидается закрытия старого процесса, заменяет EXE и запускает новую версию.
- При первом переходе со старого AppData-staging-пути приложение предлагает выбрать постоянную папку.
