# История изменений — Моя ИИшка

## 4.1.2 — дополнение: загружаемые локальные голоса и значок Windows

- Добавлен каталог загружаемых русских голосов Piper: Ирина, Денис, Дмитрий и Руслан. Голоса скачиваются прямо из раздела «Windows и голос» в папку данных приложения; каждый ONNX-файл проверяется по SHA-256.
- Добавлены просмотр доступности голоса, прогресс загрузки, прослушивание примера, выбор локального голоса и удаление ненужной модели. После загрузки голос становится выбранным автоматически.
- Автоматическое и ручное озвучивание могут использовать выбранный локальный голос Piper; системный голос Windows остаётся резервным вариантом. Загруженный голос синтезирует речь на компьютере и не отправляет текст в интернет.
- Движок Piper 1.8.0 и ONNX Runtime включены в сценарий сборки EXE; голосовые модели по запросу загружаются отдельно (примерно 60–65 МБ на голос).
- Добавлено освобождение загруженной модели из памяти перед удалением голосового файла, чтобы Windows не блокировала удаление занятой модели.
- Добавлены отдельные PNG-иконки разных размеров и явная установка больших/малых Win32-значков окна, чтобы улучшить отображение в панели задач на экранах с высоким DPI.
- Сохранены имя версии 4.1.2, поиск и удаление выбранных старых EXE-копий, а также защита текущего запущенного EXE от удаления.

## 4.1.2 — интерфейс, установка обновлений и исправление веб-поиска

- Исправлено: интернет-поиск в чате больше не требует API-ключа. Если языковая модель не настроена, показываются найденные источники, выдержки и ссылки.
- Разделены требования к веб-поиску и облачной генерации ответов: API-ключ нужен только для облачной модели.

- Добавлена постоянная тёмная верхняя панель приложения с номером версии.
- Обновлены карточки недавних диалогов: увеличены шрифт, отступы, предпросмотр и выделение активного диалога.
- Сделаны более заметные флажки: пустой квадрат означает «нет», заполненный тёмно-фиолетовый квадрат — «да».
- Увеличен базовый размер текста; сохранён шрифт Segoe UI как наиболее совместимый с Windows 10.
- Добавлен выбор постоянной папки установки и кнопка переноса текущей EXE-сборки в выбранную папку.
- Обновления после проверки SHA-256 устанавливаются в сохранённую папку; отдельный помощник дожидается закрытия старого процесса, заменяет EXE и запускает новую версию.
- При первом переходе со старого AppData-staging-пути приложение предлагает выбрать постоянную папку.
- Добавлена кнопка «Поиск устаревших версий»: поиск копий EXE в известных пользовательских папках, просмотр пути/размера/даты, выбор нескольких файлов и удаление только выбранных EXE с подтверждением. Текущий исполняемый файл защищён от удаления, данные и история чатов не затрагиваются.
- Перерисована иконка приложения в высоком разрешении 1024×1024; ICO содержит размеры 16–256 px для панели задач, окон и Проводника Windows. Добавлен стабильный Windows AppUserModelID для более согласованного значка в панели задач.
